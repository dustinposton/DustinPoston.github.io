Lab 3: Vulnerability Management

Conducted host discovery, unauthenticated scanning, authenticated scanning, risk analysis, and remediation documentation using Nessus Essentials.

Scope
Scanning network IP to discover what hosts are alive/dead and possibly scan for vulnerabilities
Methodology
First I used Nessus to find hosts that are alive within my home lab. After I would attempt a non-credential scan to see what attackers might see, and credential scan for internal vulnerabilities
Key Findings
Highest severity according to CVE rating was ICMP timestamp
Prioritization
Most issues were just information as I did not do an extensive vulnerability scan, I would prioritize the ICMP timestamp issue as attackers can use it to gain authentication through timestamps
Remediation
Restrict SNMP from unauthorized users, this is a network device concern so cutting off access and disabling timestamps would be the recommended route
Lessons Learned
I learned the most configuration issues that can be an attackers way in can be found from vulnerability scans. Scans are a good baseline to see where you're vulnerable and what you can focus on remediating immediately

Lab 4: Security Monitoring & Investigation

Generated attack telemetry from a Kali Linux system, collected endpoint logs with Sysmon, centralized telemetry in Splunk, and investigated suspicious activity through security monitoring workflows.

Objective
Investigate alert logs to identify if true positive alert. Document every indicator of compromise found and possible root cause, escalate if necessary.
Attacks Simulated
Brute-force attack, phishing attack, possible false positive simulated of employee typing wrong password
Detections
Windows Event ID 4625, 4624 (for failed/successful logins) for Splunk I was searching for the EventCode=4625 of the index and furthering my search details based on evidence.
MITRE ATT&CK Mapping
Mapped brute force attack to T1110 as they're technique and found recommendations included to document.
Lessons Learned
Not every attack is an attacker, so it is important we dig into logs and find out details before jumping the gun. On the other hand being fast and efficient can mean the difference in an attack escalating quickly to critical assets.
